# 배우가 나오는 방(이머시브) 모음

기준: **공식 안내**(매장 홈페이지·예약 페이지)에 배우·연기자·직원 NPC 가 함께한다고 적힌 것만 넣는다.
후기·기사·검색 요약만 있는 곳은 '확인 대기'에 두고, 원문을 확인하면 옮긴다.
지금 모아 보는 주소: https://bangtallog.com/search?q=배우연출 (catalog.tags 에 '배우연출')
