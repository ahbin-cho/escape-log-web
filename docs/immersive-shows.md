# 기간 한정 이머시브 공연 조사 (2026-11-14)

`docs/immersive-research.md` 는 상설 매장을 정리한 문서다. 이 문서는 그와 별개로, **예매처에서 기간을 정해 파는 공연형 이머시브**(이머시브극, 체험형 연극, 공포 체험, 크라임씬)를 모았다.
대상은 **지금 공연 중이거나 2027-02-28 전에 시작하는 작품**이다.

## 출처 표시 규칙
| 표시 | 뜻 | 카드에 써도 되나 |
|---|---|---|
| **[공식]** | 예매처 상품 페이지, 제작사·공연장 공식 사이트 | 된다 |
| **[보도자료]** | 제작사·주최사가 "밝혔다/전했다"고 인용한 기사. 매체와 날짜를 함께 적음 | 된다. 다만 바뀌었을 수 있으니 예매처 화면으로 한 번 더 확인 |
| **[취재기사]** | 기자가 현장에서 본 것을 쓴 기사(보도자료 아님) | 확인 대기 |
| **[LEAD]** | 블로그·커뮤니티·검색 요약 | **카드에 넣지 말 것** |
| — | 못 찾음 | 비워 둠 |

예매처 상품 페이지(NOL·티켓링크)는 이 세션에서 열리지 않았다(아래 '막힌 사이트'). 그래서 대부분 **[보도자료]** 수준이다. 카드를 만들기 전에 아래 '스크린샷 목록'대로 예매처 화면을 한 번 확인할 것.
