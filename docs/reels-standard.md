# 릴스·움직이는 그림 기준 (초안 2026-11-16)

운영자 피드백으로 정한 기준. 새 릴스는 이 표를 통과해야 보낸다.

## 꼭 지킬 것
1. **탈출귀는 원래 그림(`public/mascot.png`)만 쓴다.** 다른 화풍으로 다시 그리지 않는다. 표정은 움직임(둥실·덜덜·점프)과 소품(땀방울)으로 낸다.
2. **글자는 화면에 한 번에 한 줄, 영상 전체로 4줄 이하.** 정보 나열형(예약 시간·가격표)은 릴스로 만들지 않는다 → 캐러셀로.
3. **공감 장면 하나.** "방탈출 해 본 사람이면 겪어 본 순간" 하나만 잡는다(마지막 자물쇠, 힌트 쓸까 말까, 공포방 맨 앞…).
4. **속도는 실제 시간.** 타이머는 1초에 1칸, 물건은 한 번에 하나씩 움직인다. 빨리감기·마구 깜빡임 금지(부랴부랴 느낌).
5. **배경·소품은 그리기 스킬 화풍으로 그린다.** 단색 배경 + CSS 도형은 쓰지 않는다. 기본 화풍은 점토 스톱모션(`tools/ig/reel_clay/`), 장면마다 2벌을 번갈아 손맛을 낸다.
6. **긴장 → 풀림.** 어둡게 시작해 마지막에 밝아진다. 끝 화면은 사이트 색(크림 #F5F0E6·먹 #1D1D1D·주황 #E49A4A)과 SB어그로.
7. **소리가 절반.** 째깍·딸깍·탈깍처럼 장면에 맞는 효과음을 넣는다. 마지막 소리는 "탈깍".
8. 길이 10~15초, 끝에 칩 하나(한 줄)만. 사이트 홍보 문구는 캡션에(평일에만).

## 사이트 화면 기준(표·목록)
- 굵은 먹선 + 오프셋 그림자 카드, 머리줄은 주황. 회색 점선 상자·맨 칩 나열은 쓰지 않는다.
- 안내 문구는 방린이 시점, 탈출귀가 말하는 것처럼.
- 표는 값이 있는 칸만, 한 화면에 60줄 이하.
