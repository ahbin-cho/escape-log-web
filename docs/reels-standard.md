# 릴스·움직이는 그림 기준 (2026-11-16)

운영자 피드백 + 운영자가 준 "Claude 애니메이션 스타일 10가지" 자료로 정한 기준. 새 릴스는 이걸 통과해야 보낸다.

## 화풍: 10가지 중 우리가 쓰는 것
| 쓰임 | 화풍 | 왜 |
|---|---|---|
| **기본** | 7) 색종이 오려붙이기 스톱모션 | 크림 종이·겹친 그림자가 사이트의 오프셋 그림자와 같은 말투. 탈출귀를 흰 테두리 스티커로 붙이면 수채 그림 그대로 어울린다 |
| 터지는 순간 | 5) 코믹(굵은 먹선·집중선·효과음 글자) | "탈깍!" 한 컷, 굵은 먹 테두리·SB어그로와 같다. 영상 전체가 아니라 마지막 1~2초에만 |
| 문제·힌트·용어 | 2) 칠판 분필(떨리는 선) | 방탈출의 힌트판·문제 풀이 느낌. 용어 사전·퀴즈 시리즈용 |
| 지역·목록 소개 | 6) 플랫 벡터(겹겹이 흘러가는 배경) | 정보가 주인공일 때 조용한 배경 |
| 가끔 | 1) 픽셀 아트 | 미니 퀴즈·게임 느낌 낼 때만 |
| 안 씀 | 3) 글로우 · 10) 신스웨이브 · 4) PS2 · 8) CGI · 9) 브릭 | 네온·3D 는 크림 종이 브랜드와 안 맞고, 탈출귀(2D 수채)가 떠 보인다 |

그리기 스킬의 점토·손그림·그림책은 **멈춘 그림(카드·포스터)** 에 쓰고, 영상은 위 화풍을 HTML 로 직접 움직인다.

## 움직임 규칙(자료에서 가져온 기법)
1. **12fps 로 끊어 움직인다**, 조각마다 매 프레임 1~2px 흔들림. 매끈한 CSS 전환 금지.
2. 조각마다 **드롭 섀도**(겹쳐 붙인 종이), 전체에 **종이 질감을 곱하기**로.
3. 카메라는 고정이거나 아주 천천히. 주인공(자물쇠·탈출귀)은 화면 가운데 크게.
4. 배경은 겹겹이 속도를 다르게(패럴랙스). 멈춘 배경이면 소품이 살짝씩 움직인다.
5. 글자는 통통 튀며 등장(easeOutBack 을 3~4박자로), 종이 딱지에 얹는다.
6. 속도는 실제 시간: 타이머 1초에 1칸, 물건은 한 번에 하나. 타이밍은 실제 시계 기준으로 센다(그리기가 밀려도 안 밀리게).

## 내용 규칙
1. **탈출귀는 원래 그림(`public/mascot.png`)만.** 다시 그리지 않는다. 표정은 움직임(둥실·덜덜·점프)과 소품(땀방울)으로.
2. 글자는 한 번에 한 줄, 영상 전체 4줄 이하. 정보 나열(시간표·가격)은 릴스가 아니라 캐러셀로.
3. 공감 장면 하나: 방탈출 해 본 사람이면 겪은 순간, 또는 방린이가 몰랐던 것 하나.
4. 어둡게 시작해 밝게 끝난다. 끝 화면은 크림 #F5F0E6 · 먹 #1D1D1D · 주황 #E49A4A · SB어그로.
5. 효과음 필수, 마지막 소리는 "탈깍". 길이 10~15초, 끝에 칩 하나.
6. 사이트 홍보 문구는 캡션에(평일에만).

## 사이트 화면(표·목록)
- 굵은 먹선 + 오프셋 그림자 카드, 머리줄은 주황. 회색 점선 상자·맨 칩 나열 금지.
- 안내 문구는 방린이 시점, 탈출귀가 말하듯.
- 표는 값이 있는 칸만, 한 화면 60줄 이하.
