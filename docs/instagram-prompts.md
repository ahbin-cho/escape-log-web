# 방탈로그 인스타 카드 · 다른 AI(제미나이 등)용 프롬프트

인스타 카드를 직접 더 만들고 싶을 때 쓰는 프롬프트 모음.
아래 **① 브랜드 가이드**를 매번 맨 앞에 붙여 넣고, 그 뒤에 ②~④ 중 필요한 것을 붙인다.

> 이미지 AI는 한글 글자를 자주 틀리게 그린다. 글자가 들어간 카드는
> **배경·그림만 AI로 만들고 글자는 캔바/미리캔버스에서 얹는 것**이 가장 깔끔하다.
> (사이트의 카드 생성기 `/api/ig/slides`, `/api/ig/mystery` 는 글자까지 정확히 나온다.)

---

## ① 브랜드 가이드 (항상 맨 앞에)

```
너는 "방탈로그"의 인스타그램 디자이너야. 방탈로그는 방탈출 카페에 다녀온 기록을 남기는
다이어리 서비스이고, 취향 진단과 맞춤 방 추천, 친구 궁합도 제공해. 무료, 로그인 없이 시작.

[톤]
- 잡지 표지 같은 에디토리얼 스타일. 장식은 최소, 큰 글자와 여백으로 승부.
- 말투는 다정하고 담백한 존댓말. 과장(1위, 최고, 대박), 이모지 남발, 느낌표 연발 금지.
- "AI가 만든 템플릿" 느낌 금지: 네온, 그라데이션 배경, 3D 아이콘, 둥근 알약 버튼 남발, 반짝이 효과 쓰지 마.

[색]
- 배경 크림 #F5F0E6, 글자 먹색 #1D1D1D, 보조 글자 #7A736B, 얇은 선 #D9D0C2
- 포인트 주황 #E2853A 하나만. 한 장에 주황은 한두 군데만.
- 카드 상자를 쓸 때: 배경 #FFFCF6 + 먹색 3px 테두리 + 모서리 둥글기 작게

[글꼴]
- Pretendard. 제목은 ExtraBold(매우 굵게, 자간 좁게), 본문은 Medium.
- 맨 위 작은 라벨은 영문 대문자 + 넓은 자간 (예: BANGTALLOG, TODAY'S MYSTERY ROOM)

[레이아웃]
- 1080×1350(세로 4:5). 위·아래 여백 넉넉히(약 90px).
- 맨 위: 왼쪽 작은 라벨, 오른쪽 페이지 번호나 날짜, 그 아래 먹색 가로선 한 줄.
- 맨 아래: 왼쪽 "방탈로그 · bangtallog.com"(작게, 회색), 오른쪽에 마스코트 작게.

[마스코트 "탈출귀"]
- 하얗고 동글동글한 작은 유령. 수채화 느낌, 볼이 발그레하고 혀를 살짝 내민 장난스러운 표정.
- 주인공이 아니라 서명처럼 작게(화면 폭의 10% 정도).
```

## ② 다이어리 작성 유도 광고 카드 (한 장짜리)

```
위 가이드대로 "방탈출 다이어리를 쓰고 싶게 만드는" 인스타 광고 카드 1장을 만들어 줘.

[메시지 후보 중 하나를 골라 제목으로]
- "지난주에 간 방, 벌써 헷갈리지 않아요?"
- "47번째 방이었어요. 기억하고 있었어요?"
- "방 이름은 기억나는데, 누구랑 갔더라?"
- "올해 몇 방 했는지 아는 사람?"

[구성]
- 제목: 2줄, 두 번째 줄 핵심 단어만 주황.
- 그 아래 회색 한 줄 설명: "다녀온 방을 남기면 몇 번째 방인지, 올해 결산까지 알아서 정리돼요."
- 가운데: 다이어리 화면을 흉내 낸 기록 3줄 (날짜 큰 숫자 / "#47" 같은 번호 / 테마 이름 / "탈출 8분 남김" 같은 결과).
  하나는 "50번째 방" 처럼 주황으로 강조.
- 아래: "무료 · 로그인 없이 30초 → 프로필 링크"

글자는 반드시 한국어 그대로, 철자 틀리지 않게. 자신 없으면 글자 자리는 비워 두고 배경과 구성만 만들어.
```

## ③ 연말 결산 시즌 카드 (12월용)

```
위 가이드대로 12월 "나의 방탈출 결산" 홍보 카드 1장을 만들어 줘.
- 제목: "올해, 몇 방 했어요?" (두 번째 줄 '몇 방' 주황)
- 설명: "기록만 해 두면 연말 결산이 자동으로 나와요. 친구들한테 자랑은 버튼 하나."
- 가운데: 2×2 숫자 카드 (올해 플레이 47방 / 탈출 성공률 74% / 노힌트 탈출 16번 / 원정 지역 3곳)
- 아래: "지금부터 써도 늦지 않았어요 → 프로필 링크"
```

## ④ 캡션(본문) 쓰기용 — 텍스트 AI에

```
너는 방탈출 다이어리 서비스 "방탈로그"의 인스타 운영자야.
아래 주제로 인스타 캡션을 써 줘.

[규칙]
- 3~5줄. 첫 줄은 질문이나 공감 한 줄로 시작해서 피드에서 멈추게.
- 다정하고 담백한 존댓말. 과장 표현, 이모지 3개 넘게, 느낌표 연발 금지.
- 마지막 줄: "무료 · 로그인 없이 → 프로필 링크"
- 해시태그 10~15개를 맨 아래에. 섞어서:
  · 동네/지역: #강남방탈출 #홍대방탈출 #서울방탈출 (주제에 맞게)
  · 조건: #안무서운방탈출 #방탈출입문 #데이트코스
  · 커뮤니티: #방탈러 #방린이 #방탈출스타그램 #방탈출후기 #방탈출추천
  · 큰 태그: #방탈출 #이색데이트
  · 우리 태그: #방탈로그 #방탈출다이어리
- 특정 매장·브랜드를 칭찬하거나 깎아내리지 마.

[주제]
(여기에 주제를 적기. 예: "다이어리에 기록하면 몇 번째 방인지 세어 준다", "12월 결산 시작")
```

## ⑤ 장르별 배경 그림 (오늘의 미스터리 방 카드용)

오늘의 미스터리 방 카드는 장르마다 분위기가 다르다(공포·추리·감성·SF·팝).
지금은 도형으로 그리지만, 아래 프롬프트로 만든 그림을 `public/ig-bg/` 에
정해진 이름으로 넣으면 **그 그림 위에 정확한 한글을 얹어** 더 영화 같은 카드가 된다.

공통으로 맨 뒤에 붙이기:
```
세로 4:5(1080×1350). 글자·간판·로고·숫자는 절대 넣지 마(위에 따로 글을 얹을 거야).
화면 아래쪽 절반은 어둡고 단순하게 비워 둬(글자가 올라갈 자리). 사람 얼굴은 나오지 않게.
```

| 파일 이름 | 장르 | 프롬프트 |
|---|---|---|
| `horror.jpg` | 공포 | 불 꺼진 오래된 병원 복도, 끝에 살짝 열린 문 틈으로 붉은 빛. 바닥에 흩어진 서류, 깜빡이는 형광등 하나. 차갑고 축축한 공기, 필름 그레인, 영화 스틸컷 |
| `noir.jpg` | 추리·스릴러 | 비 오는 밤 골목, 젖은 아스팔트에 가로등 불빛이 번짐. 흑백 누아르 만화 스타일, 굵은 먹선, 강한 명암. 멀리 반쯤 열린 사무실 창문 |
| `dream.jpg` | 감성·판타지 | 보랏빛 밤하늘 아래 작은 다락방 창문, 따뜻한 노란 불빛, 떠다니는 종이 편지와 별가루. 수채화 그림책 스타일, 부드럽고 몽환적 |
| `scifi.jpg` | SF·아케이드 | 고장 난 우주선 조종실, 깜빡이는 하늘색 모니터 빛, 창밖으로 보이는 행성. 차가운 남색 톤, 시네마틱 |
| `pop.jpg` | 모험·코믹·기타 | 노란 배경에 보물 지도·열쇠·나침반이 흩어진 플랫 일러스트, 굵은 검정 외곽선, 장난스러운 만화 스타일 |

> 넣은 뒤 배포하면 바로 적용된다. 마음에 안 들면 파일만 지우면 도형 테마로 돌아간다.
> 미리보기: `https://bangtallog.com/api/ig/mystery?style=mood&genre=공포` (장르 바꿔 보기), `&bg=0` 은 그림 없이.
> (지금 기본 카드는 디자인 D 종이 카드라 이 배경 그림을 쓰지 않는다. `?style=mood` 일 때만 쓴다.)

## ⑥ 후킹 규칙 (모든 카드·캡션에 적용)

도슨트식 후킹 3가지를 방탈출에 맞게 옮긴 것. 카드 첫 장과 캡션 첫 줄은 이 셋 중 하나로 쓴다.

| 규칙 | 하지 말 것 | 이렇게 |
|---|---|---|
| 1. 질문으로 시작 | "상상의문 수원점의 공포 테마입니다" | "이 방, 어디인지 맞혀 볼래요?" |
| 2. 전부 말고 한 조각만 | 장르·난이도·시간·인원을 첫 장에 나열 | 매장 공식 줄거리 **한 문장**만 먼저. 스펙은 뒤 장·캡션 아래로 |
| 3. 일상 말로 바꾸기 | "난이도 5, 200분, 문제방" | "영화 두 편 볼 시간 동안 문제만 푸는 방" |

- 한 게시물에 포인트는 하나. 테마를 여러 개 넣더라도 장마다 하나씩.
- 비교 구성(✕ 스펙 소개 / ○ 한 문장 소개)과 "어떤 쪽에 더 끌려요?" 질문은 댓글을 부른다.
- 줄거리는 매장 공식 문장만 쓴다(지어내지 않기). 일상 말 비유는 사실(시간·인원·난이도)에서 벗어나지 않게.
