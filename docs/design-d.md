# 디자인 기준 (2026-11-13 운영자 확정, 최종)

**기본은 지금 bangtallog.com 의 모양이다.** 운영자가 "이전 메인이 훨씬 낫다"고 해서 홈·위 메뉴·바탕은 라이브 그대로 되돌렸다.
새 기능(포스터·예약 오픈·서재·팀 조합·미니 진단 등)은 이 모양 위에 얹는다. 아래 '디자인 D' 내용은 구조 참고용 기록이다.

## 디자인 시스템 숙제 (운영자 메모: "나중에 참고해줘")
운영자 지적: 새로 만든 화면 일부가 테두리 없이 납작해서 사이트의 다른 부분과 "디자인 시스템적으로" 안 맞는다.
- 칩·버튼·카드는 한 벌의 규칙을 쓴다 → `lib/ui.ts`(CHIP·CHIP_ON·BTN_PRIMARY·BTN_LINE). 새 화면은 직접 클래스 쓰지 말고 이걸 쓴다.
  - 칩: 흰 종이 + 연한 먹선(`border-2 border-edge/30`), 고른 칩: 주황 + 먹선
  - 버튼: 굵은 먹선 + 오프셋 그림자 + 손그림 선(rough)
  - 카드: 흰 종이(`bg-panel`) + 굵은 먹선(`border-2 border-edge`), 안에 또 카드 넣지 않기
  - 제목: 어그로체, 홈 구역 제목은 이모지 하나
- 남은 정리 대상(2026-11-13 기준): 테마 상세·내 기록·지역/브랜드/검색 목록·팀 조합·미니 진단의 칩·구분선·카드가 위 규칙과 다른 곳.
  화면마다 '라이브와 나란히' 비교 스크린샷을 보여 주고 운영자 확인을 받은 뒤 고친다.
- 디자인을 통째로 갈아엎지 않는다. 오늘 여러 번 갈아엎다가 오히려 밤티해졌다(흰 바탕 D → 색만 바꾼 D → 라이브 복귀).

# 디자인 D — 친근한 버전 (2026-11-13 운영자 확정)

> 처음 D(흰 바탕·먹색 버튼·고딕 제목)는 "딱딱하고 친근하지 않다"는 의견으로 고쳤다.
> 원래 bangtallog.com 의 느낌(크림 종이·어그로체 제목·굵은 먹선·주황 버튼과 오프셋 그림자·탈출귀·제목 이모지)을 유지하고,
> D 에서는 구조만 가져온다: 포스터가 주인공, 카드 안에 카드 안 넣기, 접히는 필터, 아래 탭 메뉴, 얇은 선 구분.

기준: "바탕은 조용하게, 주인공은 공식 포스터와 내 기록." 레퍼런스는 방도장·빠방(둘 다 사이트는 거의 무색, 색은 포스터뿐, 앱처럼 생김).

## 규칙
- 바탕은 살짝 구겨진 종이색 `bg-paper`(#F5F0E6 + 옅은 결 무늬, 운영자 요청), 카드는 흰색 `bg-panel`. 글씨 먹색 `#17171A`, 강조색은 주황 `#EE7A2B`(candy) 하나. 옅은 채움은 `bg-ink`(#ECE6D9), 선은 `border-line`/`border-edge`(#E0D9CA, 1px).
- 굵은 먹선·오프셋 그림자는 버튼과 포스터에만. 내용 구분은 얇은 선과 여백. 카드 안에 카드 넣지 않기. 손그림 선(rough)은 쓰지 않는다.
- 제목은 어그로체(SBAggroB), 본문은 Pretendard. 홈 구역 제목에는 이모지 하나씩 붙여도 된다.
- 대문자 꼬리표, 01·02 번호(순서가 아닐 때), 버튼 끝 → 화살표 쓰지 않는다.
- 주 버튼은 주황 바탕 + 먹색 글씨 + 굵은 먹선 + 오프셋 그림자(`lib/ui.ts` BTN_PRIMARY), 보조는 흰 바탕 + 굵은 먹선(BTN_LINE). 포스터 카드는 굵은 먹선 테두리.
- 주황 바탕 위 글씨는 먹색(`text-edge`) — 흰 글씨는 대비 부족.
- 포스터: `components/Poster.tsx`(2:3, 공식 포스터 없으면 장르 색 표지). 기록 → 포스터 찾기는 `lib/poster.ts` + `lib/use-poster-index.ts`(`/api/poster-index`).
  매장 포스터는 사이트 안에서만. 인스타 카드에는 쓰지 않는다.
- 휴대폰은 아래 탭 메뉴(`components/TabBar.tsx`: 홈·찾기·기록·취향·후기). 넓은 화면은 위 메뉴.
- 탈출귀는 취향 진단·빈 화면 안내에만.
- 보조 글씨는 `text-cream/70` 이상(대비 4.5).
- 움직임은 누른 것에 대한 반응만, 200ms 안팎, `prefers-reduced-motion` 지키기.

## 진행 순서
1. D 입히기: 홈 · 내 기록(달력·서재) · 테마 상세 · 탭 메뉴
2. '다녀왔어요' 빠른 기록 + 저장 보상
3. 포스터 고르기 첫 화면(가입 전 3개 고르면 서재·유형)
4. 다음에 갈 방 + 위시
5. 같이 간 사람 + 공유

## 인스타 카드 기준 (2026-11-13 운영자 확정)
- **이미 올린 시리즈에 이어지는 것은 그 시리즈의 원래 스타일을 유지한다.**
  예: 수능 이벤트(노란 쿠폰 스타일, `tools/ig/templates/sp*.html`·`sps*.html`) — EVENT 5 해피앤딩은 `sps5.html`.
- **새로 시작하는 것은 디자인 D + 유쾌한 느낌으로 만든다.**
  종이 바탕·Pretendard 제목·주황 한 단어 + 물결 밑줄, 기울인 화면, 노랑/주황 스티커, 주황 붓글씨 한마디, 탈출귀 말풍선.
  기준 예시: `tools/ig/templates/diary1~4.html`.
- 카드 속 사이트 화면에는 매장 포스터가 보이지 않게 한다(캡처할 때 `/api/poster-index` 를 빈 값으로 막아 장르 색 표지로).
- 공포 릴스는 분위기는 그대로, 끝 장면만 종이 카드("다녀왔다면 한 줄 기록").
