# 배우가 계속 연기하는 이머시브 조사 (2026-11-13)

목표: 배우가 처음부터 끝까지 연기하고 관객이 등장인물이 되는 체험(블랙뮤즈 같은 것).
배우가 잠깐 나오는 방탈출(포인트나인 LISTEN/SILENT, Memory of Poppy, 춘화각 직원 NPC)은 이번 조사에서 뺐다.

**확인 기준**: 그 브랜드가 직접 쓴 글만 인정한다.
- 공식 홈페이지
- 공식 예약 페이지: 네이버 예약, 자체 예약 페이지, 운영사 예매 페이지
- 네이버 플레이스 '업체 소개'(업주가 직접 쓴 글)

블로그·기사·후기·검색 요약은 '확인 대기'에만 둔다. 가격·시간·인원은 공식 페이지에서 읽은 것만 적고, 모르면 비워 둔다.

종류
- **연극형**: 퍼즐 없이 이야기와 연기가 중심. 꼬리표 `이머시브` + `이머시브연극`
- **방탈출형**: 테마 안에서 탐색하거나 퍼즐을 푼다. 꼬리표 `이머시브`

배우 비중: 공식 문구로 판단했다. '전 과정 동행'은 공식 글에 "함께 이동", "함께 진행"처럼 끝까지 같이한다는 뜻이 있을 때만 적었다.

카탈로그 대조: public.catalog 764행을 cafe+name 으로 비교했다. 아래 '확인됨'에 나온 작품은 **카탈로그에 하나도 없다**(전부 '없음').
