# 인스타 운영 요령 (@bangtal_log)

운영자가 앱에서 직접 하는 일을 모아 둔 것. 새 세션은 운영자에게 설명할 때 이 문서의 말투와 순서를 따른다.
(인스타 메뉴 이름은 버전마다 조금 다르다. 안 보이면 화면 캡처를 받아서 안내한다.)

## 게시물
| 하고 싶은 것 | 방법 |
|---|---|
| 여러 장 올리기 | ＋ → 게시물 → 오른쪽 위 **여러 장 선택**(겹친 네모) → 순서대로 고르기 |
| 세로 전체 보이게 | 미리보기 왼쪽 아래 **↔** 버튼 |
| 프로필 맨 위 고정 | 게시물 **⋯ → 프로필에 고정** (최대 3개). "기본 그리드에서 고정 취소"가 보이면 이미 고정된 것 |
| 캡션 고치기 | **⋯ → 수정**. 사진은 못 바꾼다 |
| 숨기기(되돌릴 수 있음) | **⋯ → 보관** |
| 보관 풀기 | 프로필 **≡ → 보관**(없으면 내 활동 → 보관) → 게시물 보관 → 게시물 **⋯ → 프로필에 표시** |
| 지운 것 되살리기 | ≡ → 내 활동 → **최근 삭제된 항목** → 복원 (30일 안) |
| 매장 태그 | 올리기 마지막 화면 **사람 태그하기**. '공동 작업자 초대'는 쓰지 않는다 |
| 내 댓글 고정 | 댓글을 왼쪽으로 밀어 📌 (업데이트 알릴 때) |
| 다시 띄우기 | 게시물 아래 **⟲ 리포스트** |
| 반응 보기 | 게시물 아래 **인사이트 보기** (도달·저장·공유) |

## 링크
- 캡션·댓글의 링크는 **눌리지 않는다**. "프로필 링크"라고 쓰고 프로필에 링크를 건다(프로필 편집 → 링크, 최대 5개).
- 눌리는 링크는 **스토리의 링크 스티커**뿐: 스토리 만들기 → 스티커 → 링크 → 주소 붙여넣기 → 스티커 글자 바꾸기.
- 주소 끝에 `?utm_source=instagram&utm_medium=story&utm_campaign=<이름>` 을 붙이면 `/admin/sources` 에서 몇 명 들어왔는지 보인다.

## 스토리·하이라이트
- 게시물을 스토리로: 게시물 아래 **✈ → 스토리에 추가**. 투표·링크 스티커를 같이 단다.
- 스토리는 24시간 뒤 사라진다. 남기려면 프로필 **＋ 새로운 하이라이트**에 넣는다.
- 하이라이트 구성: 📌시작하기 · 📍수원(지역마다) · 🎟️수능(시즌) · 🔍미스터리
- 올린 게시물의 사진을 못 바꿀 때: 새 이미지는 스토리로 올리고 하이라이트를 최신으로 유지한다.

## 릴스
- 릴스는 팔로우하지 않은 사람에게도 뜬다 → 처음 보는 사람을 데려오는 용도.
- 직접 올릴 때: ＋ → 릴스 → 영상 → **음악**(인기 음악) → 커버 고르기 → 공유. 저녁 8~9시가 좋다.
- 자동 게시 릴스에는 인기 음악을 붙일 수 없다(직접 만든 배경음이 들어 있다).

## 자동 게시와 겹칠 때
- 매일 낮 12시 자동 게시. **12시 전에 직접 올리면 그날 자동 게시는 쉰다.**
- 둘 다 올리고 싶으면 12시 이후에 직접 올리거나, 세션에 말해 그날 일정을 '추가 게시'로 바꾼다.
- 보관한 게시물은 '오늘 올린 것'으로 계속 잡힐 수 있다 → 다시 올릴 거면 보관 말고 삭제.

## 많이 보이게 하는 법 (무료)
1. 릴스로 한 번 더 2. 스토리 + 투표·링크 3. 다른 게시물 캡션 끝에 "궁금하면 👉 고정 게시물"
4. 며칠 뒤 리포스트 5. 지인에게 저장·공유 부탁 6. 동네 태그(#수원방탈출)를 맨 앞에
- 게시물 아래 **"게시물 홍보"는 유료 광고**다. 운영자가 원할 때만.
