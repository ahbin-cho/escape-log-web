# 지역 모음 캐러셀 (6장)

수원편이 기준이다: `tools/ig/templates/sw1~6.html`, 결과 `public/ig-static/suwon/`.

## 1. 테마 고르기
`https://bangtallog.com/api/ig/collection?area=<지역>&page=1..6` 가 조건별로 고른 결과를 보여 준다
(고르는 규칙은 `lib/collection.ts`: 공포 / 무공포 / 입문 / 이야기, 섹션당 4개, 같은 매장 최대 2개).
장마다 목적에 맞는 정보만: 공포=무서운 정도, 무공포=장르·난이도, 입문=난이도·시간·인원, 이야기=공식 줄거리 첫 문장.

## 2. 운영자에게 줄 제미나이 프롬프트
공통 스타일(매번 맨 앞):
```
세로 4:5(1080×1350) 인스타그램 카드용 배경 일러스트.
스타일: 부드러운 색연필·수채 느낌의 귀여운 일러스트, 따뜻한 파스텔 톤, 연한 갈색 외곽선.
하얗고 동글동글한 작은 유령 캐릭터(볼 발그레, 혀 살짝 내민 장난스러운 표정)가 장면 속에 하나 등장.
글자·숫자·간판·로고는 절대 넣지 마.
화면 위쪽 35%는 단순한 배경으로 비워 둬(제목 자리), 아래쪽 15%도 단순하게(버튼 자리).
```
장면 6개: ①표지(그 동네 상징 풍경 + 지도 든 유령, 노랑) ②무서운 게 좋다면(어두운 복도, 이불 쓴 유령)
③무서운 건 싫다면(민트, 아늑한 방) ④처음이라면(연노랑, 열쇠 든 유령) ⑤이야기가 좋다면(연보라, 책 위의 유령)
⑥마무리(노랑, 폰 들고 엄지척). 동네 상징만 바꿔 준다(수원=화성 성곽).

## 3. 글자 얹기
sw 템플릿을 복사해 그림·테마 이름·매장을 바꾼다. 위·아래 빈 띠 색을 찍어 같은 색으로 맞춘다.
카드는 2×2, 이름 줄 → (줄거리) → 매장 + 꼬리표. 뽑은 뒤 이미지를 열어 확인.

## 4. 올리기
`public/ig-static/<지역>/` 에 넣고 `STATIC_POSTS` + 일정 `static:<지역>` (스킬 ig-post).
올라가면 운영자에게: 스토리 공유 + 링크 스티커(`/region/<시도>?utm_source=instagram&utm_medium=story&utm_campaign=<지역>`) + 📍<지역> 하이라이트.
