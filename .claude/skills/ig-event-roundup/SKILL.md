# 매장 이벤트·공지 카드

## 확인이 먼저
- 운영자가 보낸 **매장 공지 스크린샷** 또는 예약 페이지에서 직접 확인한 것만 넣는다.
- 웹 검색·구글 AI 요약만으로는 넣지 않는다(작년 행사, 상시 학생 할인이 섞여 있었다).
  확인 안 된 매장은 빼고, 뺐다고 운영자에게 말한다.
- 넣을 것: 매장·지점, 혜택, 기간, 조건(본인만/중복 불가/실물 지참 등). 공지에 없는 건 지어내지 않는다.

## 카드
- 수능편이 기준: `tools/ig/templates/sp1b.html`(표지, 제미나이 그림), `sp2c.html`(쿠폰 3개).
  쿠폰 3개가 한 장 한도. 더 생기면 같은 모양으로 장을 추가한다.
- 모든 장에 "혹시 모르니 방문 전에 꼭 매장 인스타·예약 페이지에서 확인" 문구.
- "우리 동네 이벤트 알면 댓글로 제보" 한 줄(댓글 유도 + 다음 업데이트 재료).
- 시간표·가격 변경 같은 공지는 `bj2.html`(방자전) 참고: 숫자는 공지 그대로.

## 캡션·올리기
- 매장 계정을 멘션한다(리포스트 기대). DM 은 하지 않는다.
- 시즌 전에 "저장해 두세요" 예고로 올리고, 당일 스토리로 다시 띄우고, 다음 주 업데이트판.
- 올린 뒤 이벤트가 추가되면: 캡션 수정 + 고정 댓글 + 새 이미지는 스토리로.
- 우리 사이트에 없는 매장이면 운영자에게 추가 여부를 묻고, 넣는다면 SQL(`docs/sql/` 예시)로 준다.
